## 中文说明

本仓库提供 `APM32F051_ADC+I2C_OLED.zip`，用于参考 APM32F051 ADC 采样及 GPIO 模拟 I²C OLED 显示。解压后请确认 ADC 输入范围、参考电压、采样时间、OLED 控制器、I²C 地址、GPIO 上拉和显示分辨率。外部模拟信号不得超过 MCU 允许的输入电压。

### 使用建议

1. 核对目标 MCU、开发板、引脚和工具链。
2. 阅读仓库内技术说明或示例源码。
3. 在受控硬件上完成编译、下载与功能验证。
4. 更多资料请访问 [www.geehy.com](https://www.geehy.com/)。

## English

This repository provides `APM32F051_ADC+I2C_OLED.zip` as a reference for APM32F051 ADC sampling and OLED display over GPIO-emulated I²C. After extraction, verify the ADC input range, reference voltage, sample time, OLED controller, I²C address, GPIO pull-ups, and display resolution. External analog signals must remain within the MCU input limits.

### Recommended workflow

1. Verify the target MCU, board, pins, and toolchain.
2. Read the technical notes or example sources in the repository.
3. Build, program, and validate the project on controlled hardware.
4. For more resources, visit [www.geehy.com](https://www.geehy.com/).
